# Метод Марквардта - Графическая программа

Графическая программа для выполнения метода Левенберга-Марквардта (Marquardt Method) на языке Python.

## Описание

Программа реализует алгоритм оптимизации Левенберга-Марквардта для нелинейной подгонки параметров моделей к экспериментальным данным. Метод Левенберга-Марквардта является комбинацией метода Гаусса-Ньютона и градиентного спуска, что делает его эффективным для решения задач наименьших квадратов.

## Функциональность

### Поддерживаемые модели:
1. **Линейная модель**: `y = a·x + b`
2. **Квадратичная модель**: `y = a·x² + b·x + c`
3. **Экспоненциальная модель**: `y = a·exp(b·x)`
4. **Синусоидальная модель**: `y = a·sin(b·x + c)`

### Возможности программы:
- Ввод пользовательских данных (X, Y)
- Выбор модели для аппроксимации
- Настройка параметров алгоритма (максимум итераций, точность, начальное затухание)
- Визуализация результатов аппроксимации
- График сходимости алгоритма
- Вычисление статистических показателей (RMSE, R²)
- Загрузка примера данных для быстрого тестирования

## Требования

- Python 3.6 или выше
- numpy
- matplotlib
- tkinter (обычно входит в стандартную установку Python)

## Установка

1. Убедитесь, что у вас установлен Python 3.6+

2. Установите необходимые зависимости:
```bash
pip install -r requirements.txt
```

## Запуск программы

### В PyCharm Community Edition:
1. Откройте проект в PyCharm
2. Откройте файл `marquardt_gui.py`
3. Нажмите правой кнопкой мыши на файле и выберите "Run 'marquardt_gui'"
4. Или нажмите Shift+F10 для запуска

### Из командной строки:
```bash
python marquardt_gui.py
```

## Использование

1. **Выбор модели**: Выберите тип функции из выпадающего списка
2. **Ввод данных**: 
   - Введите значения X через запятую
   - Введите значения Y через запятую
   - Введите начальные значения параметров
3. **Настройка параметров алгоритма** (опционально):
   - Максимальное число итераций (по умолчанию: 100)
   - Точность сходимости (по умолчанию: 1e-8)
   - Начальное значение параметра затухания λ (по умолчанию: 0.01)
4. **Запуск оптимизации**: Нажмите кнопку "Оптимизировать"
5. **Просмотр результатов**: 
   - Оптимальные параметры отображаются в текстовом поле
   - Графики показывают результат аппроксимации и сходимость алгоритма

## Пример использования

Программа содержит встроенный пример:
1. Нажмите кнопку "Загрузить пример"
2. Данные будут автоматически загружены
3. Нажмите "Оптимизировать" для выполнения алгоритма

Пример использует экспоненциальную модель с искусственно сгенерированными данными и шумом.
